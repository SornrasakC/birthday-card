# birthday-site 🎂

การ์ดวันเกิด interactive แบบ web app — กดลิงก์เปิดบนมือถือ/คอมแล้วเล่นได้เลย
ทำให้ป๊าม๊า (อายุ 69) เป็นของขวัญวันเกิด

เป็นไฟล์ static ล้วน ๆ (HTML/CSS/JS) ไม่มี build step ไม่ต้องลงอะไรเพิ่ม

## 3 หน้าจอ

1. **การ์ด Happy Birthday 69** — มีรูปหน้าพ่อในกรอบโพลารอยด์ + ปุ่ม `click me`
2. **บทกลอน** — โชว์ทีละวรรค พร้อม *เสียงอ่านภาษาไทยจากไฟล์ MP3 ที่เตรียมไว้* และ *เพลง Happy Birthday เบา ๆ* (ไม่มีเสียงร้อง สังเคราะห์เสียงเอง)
   อ่านจบแล้วโผล่ปุ่ม **ไปต่อ** ที่จะ **หนีไปมั่ว ๆ 3 ครั้ง** ก่อนยอมให้กด
3. **พลุ** — ยิงพลุฉลอง พร้อมข้อความ _"ได้ออกกำลังกายนิ้วแล้ว ถัดไปก็ออกกำลังกายทั้งตัวนะ 💪"_

## วิธีลองเปิด

ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย (Chrome / Edge / Safari)
> เสียงจะเริ่มทำงานหลังจากกดปุ่ม `click me` (เป็นกติกาของเบราว์เซอร์)

## สิ่งที่ต้องแก้ — อยู่ที่ `config.js` ที่เดียว

| อยากเปลี่ยน | แก้ค่า |
|-------------|--------|
| รูปหน้าพ่อ | วางไฟล์ใน `assets/` แล้วตั้ง `photoUrl` ให้ตรง (เช่น `"assets/papa.jpg"`) |
| กลอน (เจ้แต่งใหม่) | แก้ array `poem` — 1 บรรทัด = 1 วรรค |
| อายุ / คำขึ้นต้น | `age`, `greeting`, `recipientName` |
| ความเร็วเสียงอ่าน / เปิด-ปิด | `speech.audioRate`, `speech.rate`, `speech.enabled` |
| ความดังเพลง / จังหวะ | `music.volume`, `music.tempo` |
| ปุ่มไปต่อหนีกี่ครั้ง | `nextDodges` |
| ข้อความหน้าสุดท้าย | `finalTitle`, `finalMessage` |

> ถ้ายังไม่ใส่รูป จะขึ้นกรอบ "ใส่รูปตรงนี้" ให้กดเลือกรูปจากเครื่องเพื่อทดสอบได้
> (แต่รูปที่เลือกแบบนั้นจะไม่ติดไปกับลิงก์ ต้องใส่ผ่าน `assets/` ถึงจะถาวร)

### อัปเดตเว็บหลังแก้ไฟล์ (ใส่รูป/กลอนใหม่)

แก้ไฟล์ในโฟลเดอร์นี้ให้เสร็จ แล้วรันคำสั่งเดียว:

```powershell
powershell -ExecutionPolicy Bypass -File deploy.ps1
```

รอ ~1-2 นาที เว็บที่ลิงก์ด้านบนจะอัปเดตเอง

> ⚠️ GitHub Pages เป็น **public** — พอ commit รูปหน้าพ่อขึ้นไป ใครมีลิงก์ก็เปิดดูได้
> ถ้าไม่อยากให้เป็นสาธารณะ ใช้วิธีอื่นแทน เช่น Netlify Drop (<https://app.netlify.com/drop>) แบบ password / unlisted

### ทางเลือกอื่น

- **Netlify Drop** — ลากโฟลเดอร์ `birthday-site` ไปวางที่ <https://app.netlify.com/drop> ได้ลิงก์ทันที
- **Vercel / Cloudflare Pages** — ชี้ root ที่โฟลเดอร์นี้ ไม่ต้องตั้ง build command

## หมายเหตุเรื่องเสียง

- **เสียงอ่านกลอน** ใช้ไฟล์ MP3 ใน `assets/audio/` ก่อน เพื่อให้สำเนียงคงที่กว่าเสียงของเบราว์เซอร์
  ถ้าไฟล์เสียงหายหรือเล่นไม่ได้ จะ fallback ไปใช้ Web Speech API ของเบราว์เซอร์
- **เพลงประกอบ** สังเคราะห์ทำนอง Happy Birthday เองด้วย Web Audio API เลยไม่ต้องแนบไฟล์เพลง
  และไม่มีปัญหาลิขสิทธิ์ไฟล์เสียง
- มีปุ่ม 🔊 มุมขวาบนไว้เปิด/ปิดเสียง
